# Changelog

Lufa packages follow [Semantic Versioning](https://semver.org/) and use [Changesets](https://github.com/changesets/changesets) to record user-facing changes.

Package changelogs are the source of truth:

- [Design system](https://github.com/grasdouble/Lufa-Design-System/blob/main/packages/design-system/main/CHANGELOG.md)
- [Tokens](https://github.com/grasdouble/Lufa-Design-System/blob/main/packages/design-system/tokens/CHANGELOG.md)
- [Themes](https://github.com/grasdouble/Lufa-Design-System/blob/main/packages/design-system/themes/CHANGELOG.md)
- [Storybook](https://github.com/grasdouble/Lufa-Design-System/blob/main/packages/design-system/storybook/CHANGELOG.md)
- [Documentation](https://github.com/grasdouble/Lufa-Design-System/blob/main/packages/design-system/docusaurus/CHANGELOG.md)
- [Playwright](https://github.com/grasdouble/Lufa-Design-System/blob/main/packages/design-system/playwright/CHANGELOG.md)
- [CLI](https://github.com/grasdouble/Lufa-Design-System/blob/main/packages/design-system/cli/CHANGELOG.md)

## Versioning

- **Patch** — fixes, documentation, tests, and backward-compatible maintenance
- **Minor** — backward-compatible features
- **Major** — breaking API changes

Pending release notes live in the repository's [changesets directory](https://github.com/grasdouble/Lufa-Design-System/tree/main/.changeset).

For upgrade guidance, see the [migration guide](/docs/guides/migration). Report undocumented changes in [GitHub issues](https://github.com/grasdouble/Lufa-Design-System/issues).
