# Card

<DarkModeCompatible />

## Overview

**Card** groups related content with a background, border, and optional shadow. Use it to create visual separation for sections and items.

<LiveDemoSection
  tabs={[
    { id: 'default', label: 'Default', content: <LiveDemo /> },
    { id: 'as', label: 'As', content: <AsDemo /> },
  ]}
/>

## Anatomy

- **Root**: The card container.
- **Content**: The card body.

## Usage

```tsx
import { Card, Text } from '@grasdouble/lufa_design-system';

export function Example() {
  return (
    <Card>
      <Text as="h2">Profile</Text>
      <Text>User details go here.</Text>
    </Card>
  );
}
```

## Props

| Prop        | Type                             | Default     | Description                                                                  |
| ----------- | -------------------------------- | ----------- | ---------------------------------------------------------------------------- |
| `as`        | `ElementType`                    | `'div'`     | Polymorphic prop to render a different element (e.g., `section`, `article`). |
| `children`  | `ReactNode`                      | `undefined` | The content inside the card.                                                 |
| `className` | `string`                         | `undefined` | Additional CSS classes.                                                      |
| `padding`   | `'sm' \| 'md' \| 'lg'`           | `'md'`      | Selects the existing card padding token scale.                               |
| `radius`    | `'sm' \| 'md' \| 'lg'`           | `'md'`      | Selects the existing card corner-radius token scale.                         |
| `shadow`    | `'none' \| 'sm' \| 'md' \| 'lg'` | `'none'`    | Selects the existing card elevation token, or no shadow.                     |

## Accessibility

Choose semantic elements with `as` to improve document structure. Ensure headings inside cards follow a logical order.

## Theming & Tokens

Card uses component tokens for its background, border, padding, corner radius, and shadow. These tokens are theme‑aware; the scale props select among existing token values and preserve the current appearance by default.

## Do / Don’t

:::tip Do
Use **Card** to group related content and actions.
:::

:::warning Don’t
Avoid deeply nested cards—they reduce visual clarity.
:::
